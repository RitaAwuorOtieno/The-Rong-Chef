## ✨ Features

### 🏠 Public Pages
- **Home** - Hero section, featured dishes, customer testimonials
- **Menu** - Dynamic menu with category filters (Appetizers, Mains, Desserts, Beverages)
- **About** - Chef's story, philosophy, achievements, timeline, and values
- **Gallery** - Image gallery with lightbox viewer
- **Contact** - Booking form with Firebase integration

### 🔐 Admin Dashboard
- **Full CRUD operations** for all content
- **Manage Featured Dishes** - Add, edit, delete homepage dishes
- **Manage Full Menu** - Edit all menu categories with prices and descriptions
- **Manage Gallery** - Add images by URL with titles and categories
- **Manage About Page** - Edit story, philosophy, achievements, values, timeline
- **Manage Contact Page** - Edit contact info, hours, social links
- **View Bookings** - See all reservation requests
- **Manage Testimonials** - Add, edit, delete customer remarks

### 📱 Responsive Design
- Mobile-first approach
- Hamburger menu on tablets and phones
- Fluid grid layouts
- Touch-friendly interface
